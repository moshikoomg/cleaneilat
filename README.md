# CleanEilat

פלטפורמת ניקיון ותפעול לדירות Airbnb באילת. אפליקציית ווב בעברית (RTL), מותאמת קודם כל לנייד, בקובץ אחד (`index.html`) עם Supabase כשרת.

**תצוגת הדגמה:** אפשר להוסיף `?demo` לכתובת האתר כדי לקבל נתוני דוגמה ומחליף תפקידים, בלי להתחבר.

## תפקידים
| תפקיד | מה רואים |
|---|---|
| מנקה (Cleaner) | משימות יומיות, קוד כניסה שנחשף ב"הגעתי לדירה", צילום מצב לפני הניקיון, התחלה עם GPS, צ׳ק-ליסט ו-4 תמונות חובה, לוח משימות פתוח, ארנק, חבר מביא חבר, מסלול מאומת |
| מנהל (Admin) | לוח שיבוץ יומי לפי מתחם (מנקה ראשי + גיבוי), בקרת איכות חיה עם אישור שמשחרר תשלום, כספים ורווחיות, אישור משתמשים ומסמכים, ניהול דירות |
| בעל דירה (Host) | סטטוס חי לכל דירה (ממתין / בניקיון כעת / מוכן לאורחים), 4 תמונות אימות, הזמנת ניקיון נוסף או דחוף |

## מבנה
- `index.html`: כל האפליקציה (HTML/CSS/JS, בלי build).
- `supabase/schema.sql`: טבלאות, הרשאות RLS, פונקציות RPC, אחסון ו-Realtime.

## לוגיקה עסקית בשרת
- **תשלום:** `admin_approve` מחשב תשלום למנקה (תעריף מקסימלי למאומתים, רגיל לשאר), מחיר לבעל הדירה (כולל תוספת דחוף) ועמלת שותף, ורושם בארנק.
- **חבר מביא חבר:** עמלה קבועה לכל דירה שחבר מנקה. העמלות נפתחות רק בחודש שבו המפנה ביצע בעצמו לפחות ניקיון אחד.
- **מסלול מאומת:** מנקים מאומתים רואים משימות חדשות מיד ודירות פרימיום (הטרמינל) בלעדית. השאר רואים משימות חדשות אחרי השהייה שמוגדרת בהגדרות.
- **קוד כניסה:** שמור בטבלה נפרדת שרק המנהל רואה. מנקה מקבל אותו רק דרך `reveal_entry_code`, ביום הניקיון, ורק אם הוא משובץ.

## הגדרת התחברות עם Google
1. ב-Google Cloud Console: יצירת OAuth Client (Web). ב-Authorized redirect URIs להוסיף:
   `https://qmcvdjvnpaaclgestgtp.supabase.co/auth/v1/callback`
2. ב-Supabase: Authentication → Sign In / Providers → Google → להדביק Client ID ו-Secret.
3. ב-Supabase: Authentication → URL Configuration → Site URL וכתובות Redirect: כתובת האתר ב-GitHub Pages.

## פריסה ל-GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.
